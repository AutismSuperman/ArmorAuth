ArmorAuth
自托管身份认证与授权平台

基于 Spring Security + Spring Authorization Server + OAuth2/OIDC

ArmorAuth 提供授权服务器、托管登录页、管理控制台、租户与组织、MFA、Passkey、联合登录、SCIM、Webhook 和 Spring Boot Starter 接入能力，适合私有化身份基础设施建设。

OA

OAuth2/OIDC

授权码、设备码、刷新令牌、发现端点、JWKS、OIDC UserInfo 和 Logout。

UI

托管身份页面

登录、授权确认、设备激活、联合身份确认、账号中心和 MFA 绑定流程统一托管。

TS

多租户管理

租户路径、issuer、应用归属、组织层级、角色、权限和成员关系。

MF

MFA / Passkey

TOTP、Passkey/WebAuthn、短信验证码、恢复码、会话管理和联系方式验证。

ID

联合身份

OAuth2/OIDC、SAML、LDAP/AD 和常见社交/企业 Provider 的统一接入。

SB

Spring Boot Starter

Resource Server、OIDC Login、当前用户上下文、Admin Client 和 Token Relay。
