Self-hosted OAuth2 / OIDC platform

统一身份认证与授权平台

ArmorAuth 基于 Spring Security 与 Spring Authorization Server， 提供授权服务器、托管登录页、管理控制台、租户与组织、MFA、Passkey、 联合登录、SCIM、Webhook 和 Spring Boot Starter 接入能力。

查看源码 快速开始
OAuth2/OIDC授权码、设备码、刷新、发现、JWKS
Multi-tenant租户路径、组织、角色与权限
Spring BootResource Server、OIDC Login、Token Relay
Hosted identity pages 登录、授权确认、MFA、设备激活、账号中心和联合身份确认页面由服务端统一托管。

面向私有化部署的完整身份基础设施

从协议端点到管理后台，从账号安全到业务服务接入，ArmorAuth 将身份平台常用能力收敛在一个可审查、可扩展的 Spring 代码库中。

A

授权服务器

支持 OAuth2/OIDC 标准端点，持久化 Client、授权、同意、JWK 和用户数据，适合自托管认证中心。

S

账号安全

覆盖密码、验证码、TOTP、Passkey/WebAuthn、MFA 策略、联系方式验证和会话管理。

F

联合身份

支持 OAuth2/OIDC、SAML、LDAP/AD 和常见社交/企业 Provider，提供外部账号绑定流程。

T

租户与组织

用租户、组织、角色和权限承载平台化、SaaS 化或企业内部多组织管理场景。

O

运营控制台

管理应用、Scope、用户、身份源、登录策略、审计、Webhook、Token 统计和 JWK 元数据。

B

Spring Boot 接入

Starter 提供资源服务器、OIDC Login、当前用户上下文、Admin API Client 和 Token Relay。

从源码到接入应用

本地评估只需要 JDK、Maven、Node.js 和数据库。生产环境建议配置稳定 issuer、HTTPS、MySQL、加密密钥和备份策略。

01 启动服务端

构建 `armorauth-server`，启动后提供登录页、协议端点和管理 API。

02 打开管理台

在管理控制台创建租户、应用、用户、组织、身份源和登录策略。

03 配置客户端

为业务应用选择授权类型、回调地址、Scope、MFA 策略和认证方式。

04 接入业务服务

使用标准 OAuth2/OIDC 或 Spring Boot Starter 验证 Token 并读取用户上下文。

mvn -pl armorauth-server -am package -DskipTests
java -jar armorauth-server/target/armorauth-server-1.0.0.jar

cd armorauth-admin-ui
npm install
npm run dev
